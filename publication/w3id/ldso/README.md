# LDSO namespace redirect proposal

Namespace: `https://w3id.org/ldso/`.

Project: https://github.com/geoknoesis/ldso

Maintainer: Stephane Fellah, Geoknoesis LLC. Contact through https://github.com/geoknoesis/ldso/issues.

This proposal covers the six currently published unversioned foundational modules. It does not claim registration, deployment, Apache integration testing, immutable version publication, or Case/Discovery publication. Version-specific redirects must be added after immutable destinations exist. The HTTP Accept handling supports explicit Turtle/RDF requests and defaults to HTML; richer preference/q-value negotiation requires deployment testing.
